# Leforse Luxury Limo

A polished marketing landing page for Leforse Luxury Limo, an executive car service operating in NYC and the tri-state area since 1991. The site communicates the brand's core values — discretion, security, punctuality — through high-impact typography and a refined warm-gold/navy color palette.

## Key Technologies

- **TanStack Start** (React SSR framework) with **TanStack Router** for file-based routing
- **Vite** bundler with `@netlify/vite-plugin-tanstack-start` for Netlify deployment
- Custom CSS (no Tailwind) using CSS custom properties and fluid `clamp()` typography
- Google Fonts: IBM Plex Sans (headings) + Zilla Slab (body)

## Running Locally

```bash
npm install
npm run dev
```

The dev server starts on `http://localhost:3000`.
